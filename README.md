# Personal Website

Minimal monochrome personal site for Tuan-Anh Ngo, built as a static GitHub Pages portfolio.

Live site: https://aanh1009.github.io/personal-landing-page/

## Design Direction

- Monochrome palette inspired by sparse research-lab websites.
- Information-first layout with resume-driven sections.
- No build system, no framework, no third-party scripts.
- Small vanilla JavaScript motion layer with reduced-motion support.
- One generated visual asset: `assets/work-signal.png`.

## Content

The site highlights:

- Summer 2027 software engineering internship search.
- Colby College CS background.
- LinkedIn and Wayfair software engineering internships.
- Applied AI and health-tech research.
- LOBster, ClearMarket, traffic sign classifier, and molecular search projects.
- Publication in IFMBE Proceedings / Springer Nature.

## Local Preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
